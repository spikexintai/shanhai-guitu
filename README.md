# 山海归途

一款水墨风横版动作游戏，使用 Godot 4.7.2 开发，目前为可玩开发版（Demo）。

## 下载游玩（Windows）

1. 下载最新版本里的 `ShanHaiGuiTu_Windows_v1.0.0.zip`（约 110MB，在 Releases 页面的 Assets 里）

   直链：https://github.com/spikexintai/shanhai-guitu/releases/download/v1.0.0/ShanHaiGuiTu_Windows_v1.0.0.zip

2. 解压到任意目录（**建议不要放在中文路径或带空格的路径下**，例如 `D:\Game\ShanHai`）
3. 进入 `山海归途_Windows版` 文件夹，双击 `山海归途.exe` 即可开始游戏

不需要安装引擎、不需要额外运行库，`exe` 已经把引擎与全部游戏资源内嵌在一起了。

### 如果被拦截

- Windows SmartScreen 提示“已保护你的电脑”：点 **更多信息** → **仍要运行**
- Windows Defender 报毒：属于 Godot 打包 exe 的常见误报，可加入白名单后再运行

## 运行环境

- 系统：Windows 10 / 11 64 位
- 显卡：支持 Direct3D 12 的显卡（集成显卡一般也能跑，画面为 2D）
- 分辨率：默认 1280×720，窗口最大化显示
- 磁盘：约 200MB
